# CSV Outputs

This subdirectory contains CSV files generated from the analysis notebooks, including calculated collapse scores, GOAT/WOAT rankings, and statistical metrics.

## Files

- **soccer_generalized_cscores.csv**: Generalized collapse scores (c1*, c2*, n1*, n2*) for soccer teams across seasons.
- **soccer_second_half_cscores.csv**: Second-half collapse scores (C1, C2, C3) for soccer teams.
- **soccer_ternary_second_half_cscores.csv**: Ternary second-half collapse scores (C2, C3) for soccer using 3-win, 1-draw, 0-loss encoding.
- **us_generalized_cscores.csv**: Generalized collapse scores for US leagues teams.
- **us_leagues_goat_scores.csv**: GOAT and WOAT scores calculated for US leagues teams.
- **us_leagues_second_half_cscores.csv**: Second-half collapse scores for US leagues teams.

These files are outputs from the analysis and can be used for further visualization or statistical analysis.
