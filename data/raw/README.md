# Raw Data

This subdirectory contains original, unprocessed datasets sourced from various external repositories and scraping efforts for the win-loss sequences analysis.

## Files and Directories

- **Matches.csv**: Raw soccer match dataset with detailed match information (results, teams, dates, stats) for multiple leagues from 2000-2024.
- **nba_sequences_1970_to_1983.csv**: Raw NBA win-loss sequences for teams from 1970 to 1983, scraped from Basketball Reference (OUTDATED // NOT IN USE)
- **nba.csv**: Raw NBA win-loss sequences for teams from 1970 to 2025, including data from 1970-1983 and later seasons.
- **MLB1926-2025/**: Collection of MLB game log text files (glYYYY.txt) for each season from 1926 to 2025, containing raw game data.
- **rescrape_nba/**: Collection of rescraped NBA data files organized by month and year from 1955 to 1983.

For data sources, scraping methodologies, and preprocessing workflows, refer to the code directory or individual file headers.
