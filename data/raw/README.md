- Matches.csv:
    Soccer data of 27 leagues across 42 countries from 2000 to 2024. Includes details of a match such as home team, away team, full time result, year, division, yellow cards, red cards, and other variables. Dataset downloaded from Github : https://github.com/xgabora/Club-Football-Match-Data-2000-2025

- nba.csv:
    NBA Data from 1970 - 2025. Includes League, Season, Team, and Sequence. Scraped from Basketball Reference, via nda_data_retrieval.ipynb.

- nba_sequences_1970_to_1983.csv
    NBA Data from 1970 - 1983. Includes League, Season, Team, and Sequence. Scraped from Basketball Reference, via scrape_nba_70s.py.
