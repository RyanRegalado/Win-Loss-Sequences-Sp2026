# GOAT Directory

This subdirectory contains Jupyter notebooks for analyzing Greatest of All Time (GOAT) rankings and evaluations based on win-loss sequences and performance metrics.

## Files

- **Soccer_GOAT_WOAT_analysis.ipynb**: Analyzes GOAT and WOAT rankings for soccer teams by calculating extreme win/loss probabilities and scores based on binomial distributions.
- **us_leagues_GOAT_WOAT_analysis.ipynb**: Calculates GOAT and WOAT scores for US leagues teams based on win-loss sequences, using binomial probability distributions.

For detailed methodologies, data sources, and analysis specifics, refer to the individual notebook files or embedded documentation.
