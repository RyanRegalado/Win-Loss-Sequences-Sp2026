# Calculations Directory

This subdirectory contains Jupyter notebooks focused on computing various metrics, collapse scores, and statistical analyses for win-loss sequences in sports data.

## Files

- **end_of_season_metrics.ipynb**: Calculates generalized collapse scores (c1*, c2*) and optimal sequence lengths (n1*, n2*) for end-of-season metrics in soccer and US leagues data.
- **generalized_c3.ipynb**: Computes generalized C3 collapse scores (n3*, max_val) for win-loss sequences in soccer and US leagues datasets using an optimized algorithm.
- **second_half_collapse_scores_soccer_ternary_version.ipynb**: Calculates second-half collapse scores (C2) for soccer teams using ternary win-loss-draw sequences, including statistical tests and visualizations.
- **second_half_metrics.ipynb**: Computes second-half metrics including sequence lengths, win counts, and collapse scores (C1, C2, C3) for soccer and US leagues data.
- **Soccer_Exterme_Collapse_Analysis.ipynb**: Analyzes extreme collapse scenarios in soccer by calculating win probabilities, second-half performance, and C1 collapse scores.
- **win_loss_utils.py**: Utility functions for calculating win probabilities, splitting sequences, and computing collapse scores (C1, C2, C3) for win-loss sequences.

For detailed setup instructions, dependencies, and notebook-specific documentation, refer to the individual files or comments within them.
