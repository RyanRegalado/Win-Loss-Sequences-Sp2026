# Soccer Preprocess Directory

This subdirectory contains scripts and notebooks for data cleaning and preprocessing of soccer datasets used in the win-loss sequences analysis.

## Files

- **Data_Cleaning_Soccer.ipynb**: Scripts for cleaning data and creating home and away dataframes. Both dataframes were concatenated to create the soccer.csv file used in our analysis.
- **Data_Cleaning_Soccer-checkpoint.ipynb**: Scripts for further data cleaning to account for team name changes mid-season and to find seasons in the raw data where there were missing values. 

For detailed preprocessing steps, data transformations, and any required dependencies, refer to the individual files or their embedded comments.
